## 📌 Описание проекта
Графическое оконное приложение на базе фреймворка **PySide6 (Qt6)**, реализующее пользовательский интерфейс для управления датасетом отзывов и анализа данных из предыдущих лабораторных работ.

### Выполненные требования:
1. **Разделение интерфейса и алгоритмов:** в файле `main_window.py` отсутствует алгоритмическая логика обработки данных — все функции и итераторы импортируются из специализированных сервисных модулей (`dataset_service.py` и `review_iterator.py`).
2. **Интерактивный выбор каталогов:** реализован выбор исходной папки датасета через системный диалог `QFileDialog.getExistingDirectory`.
3. **Генерация аннотаций:** диалог сохранения `QFileDialog.getSaveFileName` для создания CSV-аннотации исходного каталога.
4. **Реорганизация файловой структуры:** кнопки для создания плоского каталога (`<класс>_<номер>.txt`) и случайной нумерации (`0..10000.txt`) с генерацией соответствующих аннотаций.
5. **Просмотр отзывов по классам:** 5 кнопок (`★ 1` ... `★ 5`) для пошагового обхода отзывов с помощью собственного класса-итератора `ReviewIterator`.
6. **Отображение содержимого:** заголовок и текст отзыва выводятся в элементе `QTextEdit`. При исчерпании файлов срабатывает диалог `QMessageBox`.
7. **Контроль качества кода:** 100% соблюдение стандарта **PEP8** (валидировано `flake8`).

## 🗂 Структура репозитория
```text

├── dataset/             # Исходный каталог с отзывами по подпапкам 1..5

code

source venv/bin/activate

# 2. Установка зависимостей
pip install -r requirements.txt
